# @pls/lens-gap-analysis

Lens for identifying learning gaps across courses.

## Features

- Progress bars per course with colour-coded confidence
- Weak area count indicators
- Percentage confidence per course
- Sorted weakest-first to surface priority areas

## Scope

`courseTag: 'highlight'` - always shows every course; the board's course (from `LensProps.highlight`) is highlighted and the others dimmed, never hidden.

## Internal Dependencies

`lens-framework`, `substrate`, `shared-ui`
